# Modul: System

Dieses Modul bündelt in Version 5.2.04 die Systembereiche über eine Registry.
Die produktiven Routen bleiben zunächst in `app/routes`, damit keine bestehenden URLs beschädigt werden.

Geplante schrittweise Migration:
1. Updates-Modul – erledigt in 5.2.04
2. Systemstatus und allgemeine Einstellungen
3. Sicherheit und Zeit/NTP
4. Backup und DSGVO
5. E-Mail, API, Terminals
