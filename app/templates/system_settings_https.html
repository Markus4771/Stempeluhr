Installationshinweis

Empfohlen ist ein Reverse Proxy:

Browser → HTTPS/Nginx → Stempeluhr auf http://127.0.0.1:8000

Wenn Nginx noch nicht installiert ist:

sudo apt install nginx

Die erzeugte Konfiguration liegt unter:

{{ status.nginx_config_path }}

Zur Aktivierung typischerweise:

sudo cp {{ status.nginx_config_path }} /etc/nginx/sites-available/stempeluhr_https.conf
sudo ln -s /etc/nginx/sites-available/stempeluhr_https.conf /etc/nginx/sites-enabled/stempeluhr_https.conf
sudo nginx -t
sudo systemctl reload nginx

Hilfe

Selbstsignierte Zertifikate sind sinnvoll, wenn die Stempeluhr nur intern erreichbar ist und keine Ports für externe Anbieter geöffnet werden können.

Der Browser zeigt eine Warnung, bis das Zertifikat auf den PCs als vertrauenswürdig importiert wurde. Dafür kannst du oben das Zertifikat herunterladen.

Trage bei den alternativen Namen alle Zugriffswege ein, zum Beispiel 10.0.0.48, stempeluhr.local oder einen DNS-Namen aus deinem Firmennetz.
