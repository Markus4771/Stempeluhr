Hilfe: Raspberry-Clients / Multi-Terminal

Zur Terminalverwaltung

Was ist ein Terminal?

Ein Terminal ist ein zusätzlicher Raspberry Pi mit RFID-Leser und Bildschirm. Der Raspberry speichert keine Stammdaten dauerhaft, sondern sendet Buchungen über die API an den zentralen Stempeluhr-Server.

Ablauf

  1. Terminal in der Stempeluhr anlegen.
  2. Terminal-Key einmalig kopieren.
  3. Raspberry-Client mit Serveradresse und Terminal-Key konfigurieren.
  4. Client sendet Heartbeat und RFID-Buchungen an den Server.

Wichtige API-Endpunkte

GET  /api/v1/terminals/me
POST /api/v1/terminals/heartbeat
POST /api/v1/terminals/rfid/book
POST /api/v1/terminals/offline/sync
GET  /api/v1/terminals/status

Beispiel RFID-Buchung

curl -X POST \
-H "Authorization: Bearer tk_stempeluhr_..." \
-H "Content-Type: application/json" \
-d '{"rfid_code":"123456789"}' \
http://10.0.0.48:8000/api/v1/terminals/rfid/book

Offline-Puffer

Wenn der Server nicht erreichbar ist, kann der Raspberry-Client Buchungen lokal puffern. Sobald der Server wieder erreichbar ist, sendet der Client diese über /api/v1/terminals/offline/sync nach.

Sicherheit

  • Terminal-Key geheim halten.
  • Pro Raspberry einen eigenen Terminal-Key verwenden.
  • Terminals nur im internen Netz oder per VPN betreiben.
  • Verlorene Terminals sofort deaktivieren oder Key erneuern.
