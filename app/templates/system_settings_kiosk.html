Kiosk-Konfiguration

Beispiel: http://10.0.0.48:8000/raspberry

Für dein Debian 13 System ist normalerweise labwc / Wayland richtig.

Raspberry-Agent 5.2.29

Der neue Agent startet Chromium nicht mehr nur ueber eine einzelne labwc-Datei, sondern ueber systemd-user und einen Fallback-Autostart. Dadurch funktioniert der Kioskmodus besser unter Debian 13 / labwc / Wayland.

{{ agent_status or 'Noch kein Agent-Status vorhanden.' }}

Pruefung auf dem Raspberry:

systemctl --user status stempeluhr-agent --no-pager
cat /var/log/stempeluhr-agent.log
/opt/stempeluhr/scripts/stempeluhr-raspberry-agent --status

Hilfe

Nach dem Schreiben der Autostart-Datei den Raspberry neu starten:

sudo reboot

Wenn kein Browser startet, auf dem Raspberry prüfen:

which chromium
which chromium-browser
pgrep -a chromium
cat /home/pi/.config/labwc/autostart

Bei Debian 13/trixie wird meistens /home/pi/.config/labwc/autostart verwendet. Nach Änderungen ist ein Neustart nötig:

sudo reboot
