Kalender-Hilfe

Zurück zur Kalenderverwaltung Systemeinstellungen

Grundprinzip: IN und OUT

Feiertagskalender = Import IN: Feiertage werden in die Stempeluhr eingelesen und beeinflussen die Arbeitszeitberechnung.

Abwesenheitskalender = Export OUT: Genehmigte Abwesenheiten werden aus der Stempeluhr für Thunderbird, Outlook, Nextcloud, Smartphones usw. bereitgestellt.

Hilfe: Feiertagskalender

Der Feiertagskalender ist eine Eingangsquelle. Die Daten kommen entweder von einem CalDAV-Server oder aus einer iCal-Datei.

  • CalDAV: Server-URL, Benutzer, App-Passwort und Kalender-URL eintragen. Danach „Jetzt importieren“ oder „Alle aktiven Feiertagsimporte synchronisieren“ verwenden.
  • iCal-Datei: .ics-Datei auswählen und importieren.
  • Alle Feiertage löschen: löscht die lokal gespeicherten Feiertage, damit der Import sauber neu aufgebaut werden kann.
  • Arbeitszeitberechnung: aktive Feiertage reduzieren die Sollzeit, wenn diese Option aktiviert ist.

Hilfe: Abwesenheitskalender

Der Abwesenheitskalender ist ein Ausgangskalender. Er wird von externen Programmen abonniert und nicht zurück in die Stempeluhr importiert.

  • Der Kalendername ist frei wählbar. Standard ist Abwesenheit.
  • Benutzer und Passwort/Token können aktiviert werden, damit der Kalender nicht nur über den Link geschützt ist.
  • Der iCal-Link kann in Thunderbird, Outlook, Nextcloud oder auf Smartphones als Internetkalender abonniert werden.
  • Der Kalender ist bewusst nur lesend. Änderungen in Thunderbird oder Outlook werden nicht in die Stempeluhr zurückgeschrieben.

Thunderbird

  1. Kalender öffnen.
  2. Neuer Kalender → Im Netzwerk.
  3. iCal-Link aus der Stempeluhr einfügen.
  4. Falls aktiviert: Benutzer und Passwort eintragen.
  5. Kalendername prüfen und speichern.

Outlook / Nextcloud

In Outlook den iCal-Link als Internetkalender abonnieren. In Nextcloud kann der Link als Kalender-Abonnement eingebunden werden.

Wenn ein Kalenderprogramm keine Passwortabfrage unterstützt, kann weiterhin der Token im iCal-Link verwendet werden.

Sicherheit

  • Für externe CalDAV-Server immer App-Passwörter verwenden.
  • Den Abwesenheitskalender möglichst mit Benutzer/Passwort schützen.
  • Bei Zugriff außerhalb des lokalen Netzes HTTPS verwenden.
  • Bei Verdacht auf Missbrauch den Feed-Token erneuern und das Passwort ändern.
