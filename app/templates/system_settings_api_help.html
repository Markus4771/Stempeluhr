Was ist die API?

Die API ist eine Schnittstelle, über die externe Programme auf die Stempeluhr zugreifen können.

Typische Anwendungen sind n8n, Home Assistant, Grafana, ERP-Systeme, eigene Skripte oder Auswertungen.

Grundablauf

  1. API in den API-Einstellungen aktivieren.
  2. API-Key erstellen und die Rechte festlegen.
  3. Den API-Key direkt kopieren. Er wird danach nicht erneut angezeigt.
  4. Den API-Key bei jedem Aufruf als Header mitsenden.

Authentifizierung

Der API-Key kann auf zwei Arten gesendet werden.

Variante 1: X-API-Key

X-API-Key: sk_stempeluhr_...

Variante 2: Authorization Bearer

Authorization: Bearer sk_stempeluhr_...

Beispiele mit curl

API-Status / Health

curl http://10.0.0.48:8000/api/v1/health

Dashboard abrufen

curl -H "Authorization: Bearer API_KEY" \
http://10.0.0.48:8000/api/v1/dashboard

Mitarbeiter abrufen

curl -H "Authorization: Bearer API_KEY" \
http://10.0.0.48:8000/api/v1/employees

Buchung erzeugen

curl -X POST \
-H "Authorization: Bearer API_KEY" \
-H "Content-Type: application/json" \
-d '{"employee_number":"1001","type":"kommen"}' \
http://10.0.0.48:8000/api/v1/bookings

rest:
  - resource: http://10.0.0.48:8000/api/v1/dashboard

      Authorization: Bearer API_KEY

Sicherheitshinweise

  • API-Key wie ein Passwort behandeln.
  • API nur im internen Netzwerk oder über VPN verwenden.
  • Nur die benötigten Rechte vergeben: Lesen oder Schreiben.
  • IP-Filter verwenden, wenn das Zielsystem eine feste IP hat.
  • Ablaufdatum für externe Integrationen setzen.
  • API-Logging aktiviert lassen.
